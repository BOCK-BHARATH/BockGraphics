## Create a .env file
###frontend
* add the following lines to the .env file
```
API_BASE_URL=backend_url
```
###backend
* add the following lines to the .env file
```
PORT=3000

SUPABASE_URL=ur_db
SUPABASE_SERVICE_ROLE_KEY=ur_db

JWT_SECRET=super_long_random_secret
JWT_EXPIRES_IN=7d

```
